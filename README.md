## Featured Projects

### 🔒 [PhishGuard AI](https://github.com/venkatvatsav2003/PhishGuard-AI)
Multi-layer phishing detection engine combining pattern analysis, domain intelligence (WHOIS, MX, SPF), URL risk scoring, and heuristic classification. No ML dependencies — fully interpretable results.

### 🛡️ [ZeroTrust Proxy](https://github.com/venkatvatsav2003/ZeroTrust-Proxy)
Identity-Aware Access Gateway implementing Zero-Trust architecture: per-request auth, rate limiting, IP filtering, path ACLs, and structured audit logging. JWT and static token support.

### 🚨 [RansomWatch EDR](https://github.com/venkatvatsav2003/RansomWatch-EDR)
Behavioral ransomware detector using real-time Shannon entropy analysis. Detects both known and novel variants without signatures. Includes attack simulation suite for validation.

### 🔍 [Centra](https://github.com/venkatvatsav2003/centra)
Multi-layered security scanner for hardcoded secrets, API keys, tokens, and exposed IPs. Integrates with Semgrep, Trivy, and Gitleaks for comprehensive coverage. CI/CD-ready.

### 🧪 [A3VS](https://github.com/venkatvatsav2003/A3VS)
Advanced vulnerability scanner with multi-threaded processing and AI-driven reporting capabilities.

### 🔑 [Password Analyzer](https://github.com/venkatvatsav2003/Password-analyzer)
Enterprise password strength analyzer with Shannon entropy, common wordlist detection, consecutive character analysis, and HIBP breach checking (k-anonymity).

### 🔐 [Text Encryption Toolkit](https://github.com/venkatvatsav2003/Text-Encryption-using-AES-DES-and-RSA-Algorithm)
AES-256, TripleDES, and RSA-2048 encryption suite with dual Python/OpenSSL backends. Includes key management, benchmark tools, and configurable policies.

### 📊 [Excel & CSV Data Auditor](https://github.com/venkatvatsav2003/excel_auditor)
Zero-dependency data quality auditor: duplicate detection, missing value analysis, type inference, outlier detection (IQR), and comprehensive quality scoring. Generates HTML reports.
